# 리스트뷰 — 제목 폭 확대 · 오른쪽 열 정렬 (Design)

**날짜**: 2026-06-07
**대상**: 뷰어 목록 화면(`viewer/app/templates/papers.html`)의 **리스트뷰** 행 레이아웃 (705\~931행). 카드뷰·다른 화면은 무관.

## 배경 / 문제

목록 화면에는 카드뷰와 리스트뷰가 있다. 리스트뷰의 메인 행에서:

1. **제목이 너무 좁다.** 제목 오른쪽에 고정·최대폭 항목이 줄줄이 자리를 미리 차지한다:
   해시태그(최대 10rem) + 발행일(5.5rem) + venue(6rem) + 부가날짜(6rem) + 크기(3rem)
   + 진행률(3rem) + 별점 ≈ 30rem 이상. 제목(`flex-1`)이 남은 폭만 받아 금방 잘린다.
2. **오른쪽 항목 정렬이 안 맞는다.** doc_type 배지·해시태그·파일 점들이 **가변 폭 + `x-show`**
   (없으면 레이아웃에서 제거)라, 어떤 논문에 해당 항목이 없으면 그 오른쪽 열들이 통째로
   왼쪽으로 밀린다 → 행마다 열이 어긋난다. (뒤쪽 venue/날짜/크기는 `invisible` 로 자리는
   잡지만, 앞의 가변 항목이 무너지니 함께 밀린다.)

확장 패널(⌄)에는 이미 초록·전체저자·전체카테고리·외부링크가 들어간다. 따라서 숨길 정보는
**버리는 게 아니라 확장 패널로 이동**한다.

## 목표

- 리스트뷰 메인 행에서 **제목을 대폭 넓게** 보여준다.
- 오른쪽 항목을 **행마다 정확히 정렬**되는 고정폭 열로 만든다.
- 한눈 신호만 메인 행에 남기고, 부가 정보(별점·해시태그·venue·크기·부가날짜)는 확장 패널로 옮긴다.

### 비목표 (Out of scope)

- 카드뷰, 업로드/오디오 탭, 모바일 전용 재설계는 다루지 않는다(모바일은 부수적 영향만).
- 어떤 기능도 제거하지 않는다 — 전부 확장 패널로 이동(별점은 설정 기능 유지).
- 백엔드·API 변경 없음. 순수 템플릿(프런트) 변경.

## 결정한 범위 (사용자 확정: "최소")

**메인 행에 남길 것**: 제목(확대) + 저자 서브라인 · `doc_type` 배지 · 파일 점들(자산 유무
신호) · 발행일(`pub_label`) · 진행률% · 액션 버튼.

**확장 패널로 이동**: 별점, 해시태그(이미 패널에 전체 표시 → 메인 행 단일 태그 제거),
venue, 파일 크기, 부가 날짜(`paperDateLabel`).

## 설계

### 1. 메인 행 재구성 (710\~819행 영역)

- **제목 영역** `<div class="flex-1 min-w-0">`: 제목 `<h3 truncate>` + 저자 `<p>` 유지.
  오른쪽 클러스터가 반납한 폭을 받아 제목이 넓어진다.
- **오른쪽 클러스터** `<div class="hidden sm:flex items-center gap-2 shrink-0">`:
  순서대로 4개 **고정폭 셀**, 모두 빈 값에서도 `invisible` 로 자리 유지(가변 `x-show` 제거):
  1. `doc_type` 배지 — 고정폭(예: `w-16`), 가운데/우측 정렬, 값 없으면 `invisible`.
  2. 파일 점들 — **고정폭 컨테이너**(예: `w-14`)로 감싸 우측 정렬. 내부 점들의 개수가
     달라도 컨테이너 폭이 일정해 다음 열이 밀리지 않는다.
  3. 발행일 `pub_label` — 고정폭(현행 `~5.5rem` 유지), 없으면 `invisible`(현행 유지).
  4. 진행률 % — 고정폭 `w-12`, `getProgress(paper.name) <= 0` 이면 `invisible`(현행 유지).
- **액션 버튼**(⌄ / 🔊 / ✓·↺ / 🗑, 821\~873행): 변경 없음.

> 정렬의 핵심: 메인 행 오른쪽의 **모든** 셀이 내용 유무와 무관하게 같은 폭을 점유한다.
> 가변 폭(`x-show` 제거 → `invisible`) + 점들 고정폭 컨테이너로 행 간 열이 일치한다.

### 2. 확장 패널에 이동분 추가 (876\~931행 패널 내부)

기존 패널 구조(초록 / 전체저자 / 전체카테고리 / 외부링크)에 두 블록 추가:

- **별점 setter 한 줄**: 라벨 + `[1..5]` 별 버튼. 기존 `setRating(paper.name, s)` /
  `getRating(paper.name)` 를 재사용한다(메인 행에서 쓰던 hover 로직 대신 패널에서는 항상
  보이는 별 5개). HTML 주석 마커 `<!-- list-rating-detail -->` 를 블록 앞에 둔다.
- **메타 한 줄**: `venue · {size_mb} MB · {paperDateLabel}` 를 작은 회색 텍스트로 한 줄.
  각 항목은 값이 있을 때만 표시(점 구분자 포함). HTML 주석 마커 `<!-- list-meta-line -->`.
- **해시태그**: 메인 행의 단일 카테고리 태그(739\~743행)를 제거. 패널 "Categories"(899행)는
  그대로 두어 전체 태그를 계속 본다.

### 3. 모바일(<sm)

현재도 doc_type·venue·부가날짜·별점은 `hidden`/`hidden sm:*` 로 모바일에서 안 보인다.
따라서 영향은 작다. 메인 행은 제목·파일 점들·발행일을 유지하고, **크기는 패널로 이동**
(모바일 메인 행에서 제거)하여 모바일에서도 제목 폭이 늘어난다. 오른쪽 클러스터는
`hidden sm:flex` 로 데스크톱에서만 열로 노출한다.

### 4. 동작 보존

행 클릭 → 뷰어 이동, ⌄ → `toggleCardDetail(paper)` 확장 토글, 별점 → `setRating`,
진행률/날짜 헬퍼(`getProgress`, `paperDateLabel`, `getRating`) 모두 그대로 재사용한다.
삭제되는 기능은 없다(전부 메인 행 → 패널 이동).

## 테스트

### 템플릿 어서션 (pytest — `viewer/tests/`, 문자열 검사)

`papers.html` 을 읽어 다음을 확인(패널 내/외 구분에 HTML 주석 마커 사용):
- `<!-- list-rating-detail -->` 와 `<!-- list-meta-line -->` 마커가 존재한다(이동분 추가됨).
- 별점 setter 가 확장 패널 영역에 존재한다(마커 이후에 `setRating` 등장).
- 메인 행에서 단일 카테고리 태그 바인딩(`'#' + cat` 의 리스트-메인 행 인스턴스)이 제거됨 —
  카드뷰·패널의 동일 토큰과 충돌하지 않도록 마커/주변 컨텍스트로 구분해 검사한다.

> 행 레이아웃의 픽셀 정렬·제목 폭은 문자열 테스트로 검증하기 어렵다. 자동 테스트는 "이동이
> 실제로 일어났는지"만 가볍게 보장하고, **주 수용 기준은 수동 시각 확인**으로 둔다.

### 수동 시각 확인 (주 수용 기준)

Docker 재빌드 후 http://localhost:8090 → 목록 → 리스트뷰:
- 제목이 이전보다 눈에 띄게 넓다.
- 오른쪽 열(doc_type·점들·발행일·진행률)이 **행마다 세로로 정렬**된다(값이 없는 행도 어긋나지 않음).
- 확장(⌄) 시 별점·venue·크기·부가날짜·전체 해시태그가 패널에 보이고, 별점 설정이 동작한다.
- 다크모드·모바일 폭에서도 깨지지 않는다.

## 영향 범위

- `viewer/app/templates/papers.html` — 리스트뷰 블록(705\~931행)만. 카드뷰·기타 무변경.
- 백엔드·API·설정 무변경.
