# Phase 2 낭독판 평가 프레임워크 (Claude+Codex 합의 rubric)

**목적**: Codex 낭독판 스킬 산출물이 Claude 산출물과 **동일 품질**인지 정량 판정 → Phase 3(크론 이관) 게이트.
**방법(사용자 지시)**: Claude·Codex 가 각자 산출물을 직접 읽고 채점 → 점수 잠금 후 교환·논의로 결정. 정성 인상평 금지.
**출처**: Claude v0 초안 + Codex 독립 제안(2026-07-26) 종합. Codex 제안의 3단 구조를 채택.

## 기준선 원칙
**Claude 산출물 = 비교 기준이지 사실 기준이 아니다.** 사실 기준은 소스 해설판(`_ko_explained.md`)이다. Claude 의 오류를 Codex 가 반복하지 않았다고 감점하지 않는다. Claude 가 hard gate 를 실패한 pair 는 "Claude 처럼 실패"를 목표로 삼지 않고 Claude baseline defect 로 별도 기록한다.

## 구조: 3단
`hard gate (binary) → 절대 품질 점수 (100점) → Claude 대비 비열등성`

## 1. Hard gates — 하나라도 실패 시 그 산출물 전체 FAIL
1. **입력·산출 무결성**: 동일 `source_sha256`, 최종 파일/complete sidecar 일치, stale `.part` 아님.
2. **형식**: `verify_audio.sh` STATIC CHECKS PASS, YAML/HTML 메타 없음, 이미지 경로 안전, 마무리 문장 존재.
3. **모드 분량·구조**: full = 낭독 대상 고유 본문 70% 이상 + 제거 대상 외 주요 섹션 누락 없음. brief = source tier hard band 내 + `##`≥4 + 핵심 우선순위 5개 중 4개 이상.
4. **중대 사실오류 0건**: 소스에 없는 핵심 주장·수치, 방향 반전, 단위/배수 오독, 인물·기관 오인, 그림 종류·축·추세 오묘사.
5. **핵심 증거 누락 0건**: central result/limitation, 포함키로 정한 핵심 표·그림·수식 소실.

("중대" = 결론·이해를 바꾸거나 청자가 잘못 기억하게 만드는 오류. 사소한 어색함은 점수로.)

## 2. 점수 rubric — 0~4점 × 7항목 = 100점
척도: **4** 결함 없음 · **3** 명확 통과(국소 minor) · **2** 경계/수정필요(material 1건 or minor 반복) · **1** 다수 material 로 신뢰·청취성 저하 · **0** 목적 실패/오도. 가중점 = `점수 ÷ 4 × 가중치`.

| 항목 | 가중 | 채점 대상 |
|---|---:|---|
| 1. 증거 충실성·추적가능성 | 25 (critical) | 모든 주장·수치·고유명이 소스 근거, 의미·조건·예외·한계 보존, 그림 설명 실물 일치, material claim 역추적 가능 |
| 2. 모드 적합 coverage·선택 | 20 (critical) | full 침묵 축약 없음 / brief 문제·기여·방법·결과·한계 우선순위화 + 주변부 절단. 글자 수 아닌 정보 coverage |
| 3. 비산문 요소 의미 변환 | 20 (critical) | 수식·표·그림·코드·각주를 placeholder 아닌 청취 가능 의미로. 핵심 비교·대표 수치·인과/계산 직관 보존 |
| 4. 청각적 이해도·흐름 | 15 | 화면 없이 한 번 들어 문장 관계·지시대상·논증 단계·현재 위치 추적. 문장 길이·벽 문단·전환·마무리·인지부하 |
| 5. 발음 표기·낭독 안정성 | 10 | 숫자·범위·퍼센트·단위·그림/표/절 번호·모델명·약어·영어 용어가 실제 TTS 오독 없이 일관 |
| 6. 편집 절제·정보 밀도 | 5 | 연속 패러프레이즈·매체 설명·정형 비유·풀쿼트·말미 용어집·padding 없음. brief 과압축/나열도 |
| 7. 제작 완결성 | 5 | 파일명·sidecar·이미지 인접성·순수 Markdown·종료 문장 등 즉시 배치/청취 가능 |

**절대 통과**: hard gate 전부 + 총점 **≥80** + 항목 1\~5 각 **≥3** + 항목 6\~7 각 **≥2**. 항목1 날조·오독 / 항목2 핵심 누락은 평균으로 상쇄하지 않는다.

## 3. "Claude 동일 품질"(비열등성) — 동일 논문·모드 paired 비교, 모두 만족
1. Codex 산출물 **전부 절대 통과**.
2. critical 축 1\~3 에서 Codex 가 Claude 보다 **1점 이상 낮은 pair 0개**.
3. 각 critical 축 전체 pair 평균 차 **≥ -0.25점**.
4. 100점 총점 paired 평균 **≥ Claude -3점**, 개별 **-7점 미만 없음**.
5. 블라인드 최종 선호에서 Codex 가 `동급 또는 우세`인 pair **≥ 80%**.
6. 같은 결함 유형이 **2편 이상 반복** = systematic regression → 평균과 무관하게 수정 후 재평가.

## 4. 평가 대상 (최소 3편, 각 full+brief × Claude/Codex = 12 산출물)
1. **장문 기술 논문**: 수식·핵심 실험표·여러 그림·코드 중 3종+, 해설판 ≥20k. 장문 coverage·section-safe 검증.
2. **시각·정확성 고위험**: 축 단위/배수·다중 패널 차트·고유명/인명·예외 결과. 알려진 오류 패턴 검증.
3. **산문 중심**: 이코노미스트/HBR류, 수식 적고 논지·리듬·중복 제거 중요, source ≥10k(brief tier 평가 가능).
- (선택) 4번째 **80k+ 해설판**으로 compaction·장문 full 스트레스.
- source hash·선정 이유 **고정**, 결과 좋아 보이는 논문으로 교체 금지.

## 5. 채점 절차
1. **사전 고정**: 논문·source hash·생성 프롬프트·모델/버전·rubric·합격선 확정.
2. **동일 조건 생성**: 같은 소스·이미지 접근·모드. 상대 산출물을 생성 모델에 보여주지 않음.
3. **자동 게이트**: 파일/sidecar/길이/static checks 먼저. 실패해도 원인분석 채점은 가능하나 전체 판정 FAIL.
4. **블라인드 패키징**: 모델 단서 제거, 논문별 A/B 무작위·균형 배정. 본문 미수정.
5. **독립 절대 채점**: Claude·Codex 심사자가 서로 표 안 보고 A·B 를 각각 소스 대비 채점. 감점마다 `severity + 위치 + 소스/그림 근거`.
6. **청취 테스트**: 실제 배포 TTS 엔진·속도로 도입·최기술 방법·수치 결과·그림 설명·마무리 표본 청취(발음 항목은 텍스트 추측 금지).
7. **점수 잠금 후 교환**: 양쪽 scorecard 동시 공개, 그 전 총평·선호 비공유.
8. **불일치 조정**: hard gate 상충 or 같은 항목 2점+ 차 → 증거 대조. 사실은 소스/PDF/이미지로 결론(평균 금지), 취향은 평균, unresolved 는 사용자 제3 심사.
9. **reveal + 비열등성 적용**: 실패 축만 스킬 수정 → 같은 고정 세트로 재생성·재평가.

## 합의 메모 (v0 → 합의 시 반영)
- v0 #1 을 **분량 hard gate + coverage 점수**로 분리.
- v0 #2 "날조 없음"을 **중대 오류 0건 hard gate**로 승격(점수 항목 아님).
- v0 #5·#6(숫자규칙·음차)를 **발음 표기·낭독 안정성** 한 축으로 통합.
- v0 #8 형식 → 대부분 **자동 hard gate**.
- 추가: full/brief 선택 품질 분리, 실제 TTS 청취 테스트, systematic regression 규칙.
- "총점 차 ≤2" 단독 판정 폐기 → 절대 통과 + critical 비열등성 + paired 평균 병용.
