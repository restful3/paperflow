## 4. 다음 개선 라운드를 위한 교훈 (프로세스)

1. **감사(RED) 없이 스킬을 고치지 마라.** 이번 개선 항목 전부가 "실측 인용이 있는 결함"에서 나왔고, 블라인드 심사에서 그 항목들이 그대로 승부처가 됐다. 추측성 규칙 추가는 0건.
2. **블라인드 심사에는 소스의 전 모달리티를 제공하라.** 유일한 A 승(HBR 축약판 초심)은 심사관이 이미지에 접근 못 해 정당한 전사를 "검증 불가 첨언"으로 감점한 프로토콜 아티팩트였다. 이미지 제공 재심에서 뒤집힘. → 심사 프롬프트에 이미지 경로 + "실물 일치면 정당한 커버리지" 지침 필수.
3. **생성 에이전트의 "막힌 지점" 보고가 스킬 모호점 검출기다.** 3명이 13건을 보고했고 전부 규칙 충돌·미정의 케이스(용어집 낭독 여부, 연도 혼합 표기, hard\~권장 구간, 라틴 grep 과탐 등)였다. 2차 수정으로 전량 반영. 생성 지시문에 "막힌 지점 보고" 요구를 넣는 것이 싸고 효과적.
4. **게이트는 생성 중에 실작동한다.** 논문·HBR 축약판 모두 초안이 하한 미달 → 에이전트가 스스로 hard fail 판정 후 세로 확장 재작성. 양방향 밴드+실행 가능한 게이트(grep/wc)의 가치 재확인 (cf. `feedback_one_sided_length_verification`).
5. **vision 확인 의무는 환각 묘사를 실제로 잡는다.** A의 결정적 패배 2건(이코노미스트 그림 "도해" 환각, HBR 표 포기)이 모두 이미지 미확인에서 나왔고, B는 전 그림 실물 확인으로 심사에서 "실물 일치" 판정을 받았다. 단 vision 수치 읽기의 과일반화(그림 4 "460까지 30분")는 잔존 위험 — 묘사는 추세 중심, 수치는 확실한 것만.
6. **B의 잔존 실흠 유형** (다음 라운드 후보): 고유명 훼손("원정 경기장" — 규칙 반영 완료), 종합 일반화 1문장 습관, δu–δv 발견 귀속 위치 어긋남(축약 시 출처 문맥 이동), 이코노미스트 B 해설판 "여러 해치" 오타 1건.
7. **범위 밖 관찰**: 전역 스킬 `~/.claude/skills/paper-explainer-korean` 은 프로젝트 스킬과 이미 divergent(구버전 추정) — 동기화하려면 별도 결정 필요. validator 실측에서 나온 outputs/archives 동명 공존 26쌍·stale 낭독판 272건은 운영 정리 대상(오디오 배치가 sidecar 기준 자동 재생성 예정이나 확인 권장).
