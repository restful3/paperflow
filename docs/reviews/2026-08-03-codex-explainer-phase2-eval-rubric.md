# Phase 2 해설판 평가 프레임워크 — Codex 이관 게이트 (2026-08-03)

**목적**: Codex 해설판 스킬(`.codex/skills/paper-explainer`) 산출물이 Claude 산출물과 **동일 품질**인지 정량 판정 → Phase 3(배치 lane) 게이트.
**출처**: 낭독판 Phase 2 rubric(`2026-07-26-codex-audio-phase2-eval-rubric.md`)의 3단 구조를 해설판 축으로 재작성.
**고정 시각**: 생성 **이전**에 확정. 결과를 보고 기준을 고치지 않는다.

## 기준선 원칙

**Claude 산출물 = 비교 기준이지 사실 기준이 아니다.** 사실 기준은 소스 MD(`_ko.md` 또는 영문 `.md`)와 논문 폴더의 그림 파일이다.
Claude 의 오류를 Codex 가 반복하지 않았다고 감점하지 않는다. Claude 가 hard gate 를 실패한 pair 는 Claude baseline defect 로 별도 기록한다.

## 구조: 3단

`hard gate (binary) → 절대 품질 점수 (100점) → Claude 대비 비열등성`

## 1. Hard gates — 하나라도 실패 시 그 산출물 전체 FAIL

1. **입력·산출 무결성**: 생성에 쓴 소스가 아래 고정 `source_sha256` 과 일치, 최종 파일 존재, stale `.part` 아님.
2. **형식**: `scripts/verify_explainer.py` 가 `FAIL` 이 아님(`PASS` 또는 근거 확인된 `REVIEW`). YAML 헤더 정확히 1회, 파일명 `_ko_explained.md`.
3. **분량·구조**: 외국어 소스 기준 출력/소스 자수비 **≥0.6x**, 소스의 모든 `##`/`###` 섹션이 출력에 대응 존재(제거 대상인 웹 잡동사니 섹션 제외).
4. **중대 사실오류 0건**: 소스에 없는 핵심 주장·수치, 방향 반전, 단위/배수 오독(€bn→"억" 류), 인물·기관 오인, 그림 축·추세 오묘사.
5. **핵심 증거 누락 0건**: central result/limitation, 핵심 표·그림·수식 소실.

("중대" = 결론·이해를 바꾸거나 독자가 잘못 기억하게 만드는 오류. 사소한 어색함은 점수로.)

## 2. 점수 rubric — 0\~4점 × 7항목 = 100점

척도: **4** 결함 없음 · **3** 명확 통과(국소 minor) · **2** 경계/수정필요(material 1건 or minor 반복) · **1** 다수 material 로 신뢰 저하 · **0** 목적 실패/오도.
가중점 = `점수 ÷ 4 × 가중치`.

| 항목 | 가중 | 채점 대상 |
|---|---:|---|
| 1. 증거 충실성·추적가능성 | 25 (critical) | 모든 주장·수치·고유명이 소스 근거. 의미·조건·예외·한계 보존. 그림 설명이 실물과 일치. 소스 밖 평가·예찬·인과 부연 없음 (Rule 1) |
| 2. Coverage — 누락 없음 | 20 (critical) | 원문의 모든 섹션·문단·claim·숫자·인과·예외가 최소 1회 등장 (Rule 0 전반부). 분량이 아니라 정보 coverage 로 판정 |
| 3. 재진술 금지 — 중복 없음 | 20 (critical) | "[번역 문단] → [같은 내용 재설명 문단]" 쌍 0건. 인접 패러프레이즈, 수치 재진술, 재요약형 마감 에코 (Rule 0 후반부) |
| 4. 설명 부가가치 | 15 | 원문을 옮기는 데 그치지 않고 배경·직관·맥락을 더했는가. 수식은 무엇을 계산하는지 풀었는가. 한국어 평이 소스는 구조 재편·개념 보강으로 승부했는가 (Rule 5·8) |
| 5. 문체·가독성 | 10 | 전부 합니다체(해라체 상속 0). 문단 3\~5문장. 구조 재편(표·목록·소제목)이 이해를 돕는가. 번역투 없음 (Rule 2·7) |
| 6. 비유 절제·편집 규율 | 5 | 비유 0\~3개, 정형 도입구·볼드 라벨 0건. 매체 과잉설명 0\~1회. 웹 잡동사니 제거. 자명한 기초 과잉정의 없음 (Rule 3) |
| 7. 제작 완결성 | 5 | YAML 헤더·배너·`## N장.` 구조·용어집 표·이미지 참조 보존·참고문헌 처리 등 즉시 배포 가능 |

**절대 통과**: hard gate 전부 + 총점 **≥80** + 항목 1\~3 각 **≥3** + 항목 4\~5 각 **≥3** + 항목 6\~7 각 **≥2**.
항목 1 날조·오독 / 항목 2 핵심 누락 / 항목 3 이중구조는 평균으로 상쇄하지 않는다.

## 3. "Claude 동일 품질"(비열등성) — 동일 논문 paired 비교, 모두 만족

1. Codex 산출물 **전부 절대 통과**.
2. critical 축 1\~3 에서 Codex 가 Claude 보다 **1점 이상 낮은 pair 0개**.
3. 각 critical 축 전체 pair 평균 차 **≥ -0.25점**.
4. 100점 총점 paired 평균 **≥ Claude -3점**, 개별 **-7점 미만 없음**.
5. 블라인드 최종 선호에서 Codex 가 `동급 또는 우세`인 pair **≥ 80%** (3편 기준 3편 중 3편).
6. 같은 결함 유형이 **2편 이상 반복** = systematic regression → 평균과 무관하게 스킬 수정 후 재평가.

## 5. 채점 절차

1. **사전 고정**: 논문·source hash·생성 프롬프트·모델/버전·rubric·합격선 확정 (이 문서).
2. **동일 조건 생성**: 같은 소스·이미지 접근. **상대 산출물을 생성 세션에 보여주지 않는다** (기존 `_ko_explained.md` 열람 금지 — 스킬에 명시됨).
3. **자동 게이트**: `verify_explainer.py` 를 양쪽 모두에 먼저 실행. 실패해도 원인분석 채점은 가능하나 전체 판정 FAIL.
4. **블라인드 패키징**: 모델 단서 제거, 논문별 A/B 무작위 배정. 본문 미수정.
5. **독립 절대 채점**: Claude·Codex 심사자가 서로 표를 보지 않고 A·B 를 각각 **소스 대비** 채점. 감점마다 `severity + 위치 + 소스/그림 근거`.
6. **점수 잠금 후 교환**: 양쪽 scorecard 동시 공개, 그 전 총평·선호 비공유.
7. **불일치 조정**: hard gate 상충 or 같은 항목 2점+ 차 → 증거 대조. 사실은 소스/그림으로 결론(평균 금지), 취향은 평균, unresolved 는 사용자 제3 심사.
8. **reveal + 비열등성 적용**: 실패 축만 스킬 수정 → 같은 고정 세트로 재생성·재평가.

## 낭독판 rubric 대비 변경점

- 낭독판의 **비산문 요소 의미 변환**(수식·표를 청취 가능한 말로) 축은 해설판에선 불필요 → **설명 부가가치**로 대체.
- 낭독판의 **발음 표기·낭독 안정성**(TTS 오독) 축 삭제 → 해설판은 읽는 물건이다. 대신 **문체·가독성**(합니다체·문단 길이·구조 재편)을 승격.
- 낭독판의 **모드 적합 coverage**(full/brief 분기) → 해설판은 단일 모드이므로 **Coverage**와 **재진술 금지**를 각각 독립 critical 축으로 분리. 이 둘이 해설판의 알려진 양대 결함(누락 / 번역-재진술 이중구조)이기 때문이다.
- 실제 TTS 청취 테스트 단계 삭제.
